# Seedream Studio

豆包 Seedream（火山方舟 AgentPlan）生图的图形工作台：侧边栏整页 UI + agent 工具，两条入口共用同一套生成实现。

## 它做什么

- **一个整页工作台**：写提示词、选模型（自动 / Flash / Pro）、选尺寸（1K / 1.5K / 2K）、加参考图，点一次生成，图片直接落到本地目录。上方支持 `⌘ ↵` 直接生成，生成中有计时与进度，可随时取消。
- **参考图用上传**：拖进来、`⌘V` 粘贴截图、或点按钮选文件，三种都行；缩略图可单独删除。命令行用户仍然可以展开「或者直接填路径 / 链接」手填。
- **用 `@` 引用图片**：在提示词里敲 `@` 弹出已上传的图片列表，`↑↓` 移动、`↵` 确认、`Esc` 取消，也支持鼠标点选。插入的格式是 `@图片1`、`@图片2`（按上传顺序），**不含路径**——参考图本来就随请求单独发送，提示词里塞临时路径没有意义。引用在输入框里以 DSH 同款蓝色底纹显示，和普通文字一眼能区分；在引用后面继续打字**不会**再把面板弹出来。
- **「更多选项」默认展开**：水印 / 提示词增强这些开关默认可见，需要时也可收起。
- **没有「交互式精修」和「拆图层」**：开发者自己没有这类需求，所以没有实现——代码里也没有半成品残留。如果这对你是刚需，用豆包的生图 skill **`byted-ark-seedream-skill`**，它带完整的交互编辑与拆图层能力。界面「更多选项」底部也写了同样的说明和这个名字。
- **提示词框足够大且不会乱跑**：固定 `resize:none`（拖不动，避免误拖改布局），高度是原来的两倍，长文本超过上限时内部滚动而不是把按钮顶走。
- **一个 agent 工具**：`seedream_generate`，参数与界面一致，返回本地绝对路径。界面和工具都调用宿主侧的同一个 `runGeneration()`，结果结构完全相同。
- **历史会持久化**：生成记录保存在 `$DSH_HOME/seedream-images/.history.json`（点文件，Finder 默认不显示），所以重启 DSH 后「最近生成」还在，那些图也仍然可以预览和删除。
- **默认存到 `$DSH_HOME/seedream-images`**：不写桌面，也不写插件安装目录（那里卸载/升级会丢图）。插件只往里写图片，不落 metadata JSON；历史索引是点文件 `.history.json`（Finder 默认不显示）。浏览器和 Finder 可能自行产生 `.DS_Store`，插件不管它。
- **结果就是文件**：每张图都能 打开 / 在 Finder 中显示 / 复制路径 / 复制链接，另有一张放大预览。图片预览通过插件自己的路由读取，只允许访问本插件产出过的文件。
- **产物可以删、可以批量删**：删除在「最近生成」里做——每条记录下方是该次生成的缩略图，可勾选多张批量删除，也可单张点 ×。删除是把文件移到废纸篓（`~/.Trash`），可从那里恢复，不是不可逆删除。结果区只做展示。
- **提示词增强带「！」说明**：开关旁边有一个「！」图标，**鼠标悬停或键盘聚焦**即弹出说明 —— 它在**本地**往提示词后追加画质描述，不调模型、不发额外请求、不多花钱。

## 重要限制：仅支持 Agent Plan

本插件只接受**火山方舟 Agent Plan** 的 Key（`ark-` 前缀）。界面上常驻一条提示；提交保存时也会先校验格式，不是 `ark-` 开头会直接说明原因，而不是等生成失败才报错。

## 依赖

**没有运行时依赖。** 生图能力全部内置在本包里（`lib/seedream-api.js`），不调用任何外部 skill、不需要 `npm install` 拉额外包、不启动子进程。装好插件即可用。

这么做有两个原因：一是发布时不必携带或转发第三方代码，升级与责任边界都清楚；二是省掉子进程，能直接拿到真实的 HTTP 状态码与接口错误码，进度也是真进度而不是解析 stderr 猜出来的。

内置实现覆盖了生成所需的全部环节：模型与能力校验、参数规范化、请求构造、媒体下载（含 SSRF 校验与 DNS 钉扎）、本地参考图读取与尺寸校验、结果落盘。没有移植的是与本图形界面无关的部分：CLI 参数解析、模型注册表远端同步、流式输出。

## 它不做什么

- 不自动重试。每次生成都会真实计费，失败就失败，由你决定要不要再来一次。
- 不支持 3K / 4K、组图、联网搜索、流式。当前两个模型（`doubao-seedream-5-0-flash`、`doubao-seedream-5.0-pro`）都不支持这些，界面里把选项明确禁用并说明原因，不会静默降级。
- **Key 存 DSH 凭据库，不落插件目录。** 点右上角「配置 Key」填入，写进 `~/.dsh/.credentials.yaml` 的 `ARK_AGENT_PLAN_API_KEY`——和 DSH 里其它工具共用同一套凭据管理。**开源项目特别在意这点**：Key 若存在插件自己的目录里，别人 clone 后一不小心就跟着提交了；存进 DSH 主目录则天然在仓库之外。界面只显示打码指纹（如 `ark-b58…23fa`），不回显明文、不写日志。换 Key 或清除随时可做，入口常驻标题右侧。**Key 不读任何环境变量**（保存路径另有 `ARK_SEEDREAM_SAVE_PATH`，见配置段）：没配就没配，装好后唯一来源就是你手动填的这一条，不会因为你 shell 里恰好有某个 `ARK_API_KEY` 而悄悄替你花钱。
- 不做模型注册表的远端同步、不组图、不联网搜索。只内置当前两个模型的能力与限额，参数不合规时在本地就拦下并说明原因，不会偷偷换成别的模型。
- 不做不可逆删除。macOS 上是移动到 `~/.Trash`（可用 Finder 恢复），并且刻意**不调用** `osascript`/Finder —— 那需要「自动化」权限，没授权时会弹窗把操作挂住，比删失败更糟。

## 配置

配置写在 `cordis.patch.yml` 的 Loader 记录里，全部可省略：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `savePath` | `$DSH_HOME/seedream-images` | 图片保存目录；改此项即可换位置 |
| `defaultModel` | `auto` | `auto` / `flash` / `pro` |
| `defaultSize` | `2K` | `1K` / `1.5K` / `2K` |
| `defaultOutputFormat` | `jpeg` | `jpeg` / `png` |
| `historyLimit` | `20` | 内存里保留的生成记录条数（1–200） |

保存目录还可以用环境变量 `ARK_SEEDREAM_SAVE_PATH` 指定（优先级低于上面的 `savePath`）：配置项适合长期设定，环境变量适合临时切到别处试一次。**注意这是唯一被读取的环境变量**，Key 绝不走环境变量。

## 实现要点

- **内置实现，不起子进程**：Host 直接 `import` 内置模块发 HTTPS 请求并把图下载到本地，拿到的是真实状态码与错误码，不是从 stderr 反推的文本。
- **密钥只走内存**：从 DSH 凭据服务取 Key，只用于拼一次 `Authorization` 头；不写日志、不回显、不在插件目录留副本。
- **不用 `@deepseek-ai/*` 的 import**：插件被 link 安装后解析路径不在 profile 的 `node_modules` 里，裸包名 import 会在加载期 `ERR_MODULE_NOT_FOUND`。因此工具定义是普通对象、`output.schema` 是手写 JSON Schema（对象级 `required` 数组，不能用 `defineTool` 专有的内联 `required: true`），config 用普通 JS 校验。
- **路由自带信任栅栏**：`webServer.register` 的原始路由不过 admission，所以每个处理函数都先判 `sec-fetch-site` / Host / 回环，能取到 `connection.requestRejection` 就交给它，取不到就只允许回环 —— 这些接口能触发付费生图、能读本地文件、能打开访达。
- **预览白名单**：`/image` 只读本插件产出过的绝对路径，不做任意路径读取。
